# Сайт Эндаумент-фонда науки и образования

Статический сайт на трёх языках: русский (корень), казахский (`/kz/`), английский (`/en/`).

## Как устроено

- `build.js` — разметка страниц. `node build.js` собирает сайт в папку `public/`.
- `i18n/ru.js`, `i18n/kz.js`, `i18n/en.js` — все тексты сайта по языкам. Чтобы поменять текст, правьте нужный файл.
- `static/` — стили, скрипты, логотипы (RU/KZ/EN) и паттерн.
- `netlify.toml` — Netlify сам запускает сборку при каждом изменении в репозитории.

## Что заменить перед запуском

- Фото: блоки-заглушки с паттерном (`class="ph"`).
- Цифры «₸ 00 млрд», «000+», реквизиты, телефоны, адрес, имена «Имя Фамилия» — во всех трёх файлах i18n.
- Данные графика на странице «Отчёты» (массив `CHART` в `build.js`).
- Ссылки на PDF-документы и соцсети (сейчас `#`).
- Домен в константе `SITE` в `build.js` (сейчас `https://endowment.kz`).
